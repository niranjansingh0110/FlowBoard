# Flowboard

Flowboard is a MERN stack project management app for organizing workspaces, managing projects and tasks, assigning work, tracking progress, and collaborating with a team.

## Planned stack

- MongoDB and Mongoose
- Express and Node.js
- React

## Planned features

- User accounts and workspaces
- Team members and role-based access
- Projects and task boards
- Task assignments, priorities, and due dates
- Comments and activity history

## Project status

Planning and initial setup.
